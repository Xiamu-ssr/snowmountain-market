# dsh-wind-aifin

Credential-safe Wind AIFin integration for DeepSeek Harness (DSH).

The plugin exposes Wind's official financial MCP domains as native DSH tools
and adds a native Wind Alice analysis tool. `WIND_API_KEY` stays inside DSH's
credential boundary and is never copied into model-visible shell sessions.

This is a community adapter and is not an official Wind product.
